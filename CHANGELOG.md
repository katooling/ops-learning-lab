# Changelog

All notable public changes are recorded here.

## 0.1.0 - 2026-07-24

### Added

- Private, content-addressed capture with provenance and conservative Pack
  Match proposals.
- Explicit bounded Codex imports for Capture Mode and Learn Mode.
- Immutable staged Pack Updates with previewed, explicit Promotion.
- One strict synthetic Codex ETL Learning Pack and deterministic
  evidence-centered lesson.
- Local Product Shell with keyboard and narrow-viewport support.
- Append-only Learner Attempt history, exact resume, later review, and Retained
  mastery.
- Immutable standalone export approval, offline HTML export, and privacy
  receipts.
- Current-tree and complete-history publication audits.
- One release verification command covering unit, install, history, browser,
  and publication gates.

### Safety

- Raw intake and learner history remain outside publishable stores.
- Promotion and export fail closed on stale identities, unsafe filesystem
  boundaries, unknown fields, and configured private canaries.
- Repository history must use approved no-reply identities and contain no
  unsafe reachable blobs before version 0.1.0 can be tagged.

See [Version 0.1.0 limitations](docs/limitations.md).
